Quarto Mermaid Diagrams

About Mermaid Diagrams

  • Mermaid is a JavaScript-based diagramming tool that allows you to create diagrams and visualizations directly in your Markdown documents. Mermaid looks different in HTML vs Typst PDF because it is rendered through different pipelines.

  • In HTML, Mermaid is usually rendered by the browser using JavaScript: So the diagram can use browser fonts, CSS, responsive layout, scrolling, and available screen width.

  • In Typst PDF, Quarto has to turn the Mermaid diagram into a static graphic first, then place that graphic into the PDF:

  • That means the diagram is constrained by the PDF page size, margins, figure box, image scaling, and whatever renderer Quarto uses behind the scenes

Common differences:

  • Page size is fixed in PDF: HTML has flexible width; PDF has a hard page boundary.
  • Fonts differ: browser fonts and PDF fonts may not match.
  • Scaling differs: a diagram may be shrunk to fit a Typst page.
  • Wide diagrams suffer more: flowchart LR, sequence diagrams, and Gantt charts often get compressed.
  • CSS behaves differently: HTML CSS does not necessarily affect the static diagram used in Typst.
  • Interactive widgets disappear: HTML can render interactive/responsive content; PDF gets static output only.
  • Captions and figure sizing differ: fig-width/fig-height are interpreted differently across formats.

A typical fix is to use format-specific options:

  • %%| fig-width: 10
  • %%| fig-height: 6
  • %%| fig-align: center
  • %%{init: {“theme”: “default”, “themeVariables”: {“fontSize”: “12px”}}}%%
  • flowchart TD
    • A[Student applies] –> B[University verifies documents]
    • B –> C{Complete?}

For wide diagrams in Typst/PDF, use a landscape page:

  • #pagebreak()
  • #page(flipped: true)[

Mermaid diagrams can be placed on a landscape page in Typst PDF to give them more horizontal space. This is especially useful for wide flowcharts, sequence diagrams, and Gantt charts that may not fit well on a standard portrait page.

  • %%| fig-width: 11
  • %%| fig-height: 6
  • %%| fig-align: center
  • graph TD
    • A[Start] –> B{Is it working?}
    • B – Yes –> C[Great!]
    • B – No –> D[Check the code]

Short version:

HTML renders Mermaid as a web diagram; Typst PDF embeds it as a fixed-size print graphic. So for PDF, you often need larger figure dimensions, smaller Mermaid fonts, more vertical layouts, or landscape pages

Admission 1 to 1 Process

%%{init: {"theme":"forest", "sequence": {"showSequenceNumbers": true, "mirrorActors": false}}}%%

sequenceDiagram
    actor Student
    participant University
    participant Admissions as Admissions Office
    participant Portal as Application Portal
    participant Committee as Review Committee

    Student->>Portal: Create account
    Portal-->>Student: Confirm registration

    Student->>Portal: Submit application form
    Student->>Portal: Upload transcripts and documents
    Student->>Portal: Pay application fee if applicable

    Portal->>Admissions: Forward completed application
    Admissions->>Admissions: Verify documents

    alt Documents incomplete
        Admissions-->>Student: Request missing documents
        Student->>Portal: Upload missing documents
        Portal->>Admissions: Send updated application
    else Documents complete
        Admissions->>Committee: Send application for review
    end

    Committee->>Committee: Evaluate application

    alt Accepted
        Committee-->>Admissions: Recommend admission
        Admissions-->>Student: Send offer letter with Fee Due date
        Student-->>Admissions: Accept offer
        Student-->>Portal : Pay Fees (Part/ Full)
        Note Right of Student: Student can pay fees in installments <br/> if allowed by the university
        Admissions-->>Student: Confirm Fee Payment
        
        Admissions-->>Student: Send enrollment instructions
        Note Right of Portal: Student can access the portal <br/> for enrolment  and program registration <br/> and other information after full payment only
    else Waitlisted
        Committee-->>Admissions: Place on waitlist
        Admissions-->>Student: Notify waitlist status
    else Rejected
        Committee-->>Admissions: Decline application
        Admissions-->>Student: Send rejection notice
    end

Theme for mermaid diagrams

The theme can be set in the YAML header of the Quarto document. The theme can be set to one of the following: default, forest, dark, neutral, base, or custom. The theme can also be customized using themeVariables.

The themes, roughly:

  • default: standard Mermaid look
  • neutral: cleaner, more publication-friendly
  • dark: dark background styling
  • forest: green-toned theme
  • base: customizable theme, best when using themeVariables
