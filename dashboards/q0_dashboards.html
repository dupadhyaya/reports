Types of Dashboard in Quarto

Quarto dashboards can be built in several styles depending on what you want: static reporting, interactive exploration, live apps, or multi-page analytical products.

1. Static HTML Dashboard

Good for reports that render once and are shared as HTML.

---
title: "Sales Dashboard"
format:
  dashboard:
    embed-resources: true
---

Uses R/Python chunks, charts, tables, value boxes, etc. Interactivity can come from plotly, DT, leaflet, reactable, and similar widgets.

2. Self-Contained Dashboard

Same as above, but packaged into one HTML file.

format:
  dashboard:
    embed-resources: true

Best for emailing or uploading a single file.

3. Dashboard With Pages

You can create multiple dashboard pages using top-level headings.

# Executive Summary

## Row

# Category Analysis

## Row

# Data Table

## Row

Each # heading becomes a dashboard page/tab.

4. Row/Column Layout Dashboard

Use headings like ## Row and ## Column to control layout.

**5. Dashboard With Value Boxes**

Good for KPI-style layouts.

```r
#| content: valuebox
list(
  title = "Sales",
  value = "$2.3M",
  icon = "cash-stack",
  color = "primary"
)

6. Interactive Widget Dashboard

Uses HTML widgets:

plotly::ggplotly(p)
DT::datatable(df)
leaflet::leaflet()
reactable::reactable(df)

Good for filtering, tooltips, sorting, maps, and tables.

7. Shiny Dashboard

Good when you need live filters, reactive charts, user inputs, and server-side interactivity.

---
title: "Interactive Sales Dashboard"
format: dashboard
server: shiny
---

Then use Shiny inputs:

selectInput("region", "Region", choices = unique(df$Region))
plotOutput("sales_plot")

8. Observable JS Dashboard

Good for JavaScript-based interactive visualizations.

---
title: "Observable Dashboard"
format: dashboard
---

Use Observable cells:

```{ojs}
viewof category = Inputs.select(["Furniture", "Technology", "Office Supplies"])
```

9. Python Dashboard

Use Python chunks with pandas, plotly, matplotlib, seaborn, great_tables, etc.

---
title: "Python Dashboard"
format: dashboard
jupyter: python3
---
import pandas as pd
import plotly.express as px

10. Multi-Format Dashboard

You can define different output formats:

format:
  dashboard:
    embed-resources: true
  html:
    toc: true
  typst:
    toc: true

But dashboard format is mainly for HTML.

11. Website Dashboard

You can include dashboards inside a Quarto website.

project:
  type: website

Then pages like:

index.qmd
dashboards/sales.qmd
dashboards/profit.qmd

12. Parameterized Dashboard

Useful for rendering the same dashboard for different regions, departments, or time periods.

params:
  region: "West"

Then in R:

df_region <- df |> filter(Region == params$region)

Render with:

quarto render dashboard.qmd -P region:West

Common choices:

  • Simple shareable dashboard: static/self-contained dashboard
  • Tableau-like dashboard: dashboard + plotly + DT
  • True filter controls: Shiny dashboard
  • JavaScript-heavy interactive dashboard: Observable dashboard
  • Reusable regional dashboards: parameterized dashboard
  • Portfolio/reporting hub: Quarto website with dashboard pages
